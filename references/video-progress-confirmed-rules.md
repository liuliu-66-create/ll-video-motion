# 视频章节进度条：已确认流程与样式规则

本文件是用户确认记录。规则现已落入独立的 `skills/ll-video-progress`，两款样式已注册到共用 Playground。后续制作以该 Skill 的 SKILL.md 和 references 中的规则为准。

## 用户使用流程

1. 用户提出制作进度条。已有 SRT 时直接使用，否则请用户提供 SRT 字幕。
2. 根据字幕语义建议章节，默认 3～4 段、通常不超过 5 段；用户指定的划分优先。
3. 给出简短章节标题，并引用原话说明每段从哪句话到哪句话，不要求用户核对时间码。用户确认后再继续。
4. 打开 Playground 展示已经内置的真实动态样片，让用户直接回复样式名称。不要让用户判断静态/动态实现、逐帧技术、编码或其他内部分类。
5. 已选样式和已经提供的素材不重复询问。需要的画面比例尚不明确时补齐；选“人物领走”后，先问用户是否有自定义人物图。用户明确没有或选择默认时使用当前黄头巾人物；有图则接收并制作。已提供图或明确选择时直接复用；未回复不等于没有。
6. 根据 SRT 实际时间制作，保留配置和可复用人物素材。先检查实际输出，再交付可叠加的文件。8 秒展示样片与按字幕制作的全长素材必须区分。

用户可以先指定样式，也可以先提供字幕；保留已经确认的信息，但默认流程为“字幕 → 分段确认 → Playground 选样 → 生成”。

## 共用规则

- 使用窄条独立素材，不依赖渲染整个原视频。视频画面比例与素材自身的窄条比例是两个概念。
- 横条为直角矩形，两端没有圆弧，不因增加人物改成胶囊形，也不擅自改变原有文字和分隔线。
- 未播放部分使用朦胧的半透明白底，允许看到下方内容；不是深绿色底，也不是实时模糊下方视频。
- 进度填充色可配置为任意 RGB 颜色。绿色或黄色均只是示例，不能固定成不可修改的样式限制。
- 同一次配色在预览、样式配置和最终透明文件中一致。Playground 提供取色器及色号输入；选样后正式导出沿用所选颜色。
- 除进度条和可选人物之外，其余像素必须透明；不要把预览底色、斜线、棋盘格或整幅黑色画布烘焙进素材。
- 已验证可用的交付方式为窄条 ProRes 4444 MOV，保留透明通道。浏览器可用透明 WebM 展示，但不能将浏览器播放成功等同于剪映导入成功。
- 之前的全画布 QTRLE MOV 虽通过文件 alpha 检查，用户导入剪映时仍出现黑底。因此技术检查不能代替目标软件的实际叠加验收。用户已确认新版 ProRes 4444 MOV 的透明效果和人物大小满意。

## 样式一：朦胧白底章节进度条

- 已有样式 ID 为 `soft-white-green`，绿色是默认配色，不是功能边界。
- 保留白色章节文字、细中性描边和竖线分隔。
- 各章节等宽，每段内部按本段的时间推进；章节切换对应确认的字幕边界。
- 在 1440 像素宽的设计基准下，条高为 64 像素；可按任务配置调整高度。

## 样式二：人物领走章节进度条

该样式只比样式一增加人物，进度条本身沿用同一套绘制规则，不另外设计背景、形状、字体或圆角。

- 人物在填充前沿领着进度移动，身体向下放；不能踩在横条顶上走。
- 人物完整高度与横条高度相同。按当前基准，人物最高 64 像素，条高 64 像素。
- 人物向下超出横条的部分最多为半个条高：当前基准最多 32 像素。
- 当前完整素材尺寸为 1440×96：上方 64 像素是横条，额外 32 像素容纳人物下半部分，其余像素透明。以后调整条高时按同样比例计算；不要因为人物加入而输出一整幅 4:3 不透明画布。
- 人物走路动作由一组原地迈步姿势循环播放实现，位移由时间轴程序单独控制。动作图中的人物不需要逐帧向右移位。
- 动作素材保持同一人物、朝向、比例、身体锚点和尺度，检查手脚变化、循环衔接、抖动及边缘裁切。首尾位置应保证人物完整显示。
- 可以更换人物。用户已有合格的透明走路动作图时直接使用；只有人物参考图时先生成连续原地走路姿势，预览确认后再合成。不要把静态人物平移冒充走路。
- 可选择保留一张静态人物图作为兼容素材，但不把“静态人物/动态人物”强加成用户必须判断的流程。
- 目前内置人物来自用户自己的黄头巾、圆墨镜、黑长发、黄色衣裙和黄书形象。当前接受的 8 帧动作素材未保留书封英文；用户在此条件下确认了样式，不能由此推导以后所有人物都可以省略原图文字。

## Skill 与 Playground 的建议职责

- 独立的 `ll-video-progress` 负责上述字幕、分段、选样、人物替换、配色和透明导出流程。
- `ll-video-motion` 继续负责按文案制作独立短动效及章节过渡，只保留指向独立进度条 Skill 的简短路由，不重复维护进度条实现。
- Playground 可共用一套页面和素材服务。进度条 Skill 打开进度条分类，Video Motion 打开短动效分类范围；不要求用户知道素材归属的目录或代码位置。
- 每种视觉样式各自登记名称、真实动态样片、可配置参数和验收状态，不能每增加一种样式就创建一个 Skill。
