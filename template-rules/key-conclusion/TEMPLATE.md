# 重点结论模板规则

## 用途

用于强调一句必须让观众记住的结论，例如“先有音频，再定时长”。它不是普通标题页，也不用于承载多个并列观点。

## 可替换内容

- 小标签：默认是“重点结论”，也可以替换为“核心提醒”“记住这点”等短标签。
- 主结论前半句。
- 主结论后半句。
- 镜头时长。

主结论默认使用“前半句＋逗号＋后半句”的结构。两部分必须是一句完整结论，不能塞入一段逐字稿。

## 布局规则

- 灰白旧报纸背景、中央米白纤维撕纸、砖红衬纸和四周装饰的位置固定。
- 小标签放在中央撕纸左上区域，并在砖红标签贴纸内部双向居中。
- 主结论放在中央撕纸的文字安全区内，整体双向居中。
- 前后半句可以分批入场，但最终必须组成一行完整结论。
- 文字过长时只缩小字号，不拉伸贴纸、不移动文字中心、不压到撕纸边缘。
- 禁止添加横线、发光、高亮框和具体场景图标。

## 字体与磨损规则

- 标签和主结论从出现到结束始终使用同一套旧印刷磨损效果。
- 磨损纹理由固定素材 `public/assets/distressed-ink-wear-v1.png` 提供，不能每次随机生成。
- 禁止先使用干净字体，再在结尾切换成带磨损的效果图。
- 禁止用整张确认图覆盖最终画面来校准字体。
- 磨损只允许形成少量掉墨和细小刮痕，不能出现规则横条或大面积断笔。

## 动效顺序

1. 无文字底图轻微上移并淡入。
2. 小标签从原位置附近轻微缩放进入。
3. 主结论前半句从左侧小幅进入。
4. 主结论后半句从右侧小幅进入。
5. 全部元素保持稳定，不再切换图层或字体。

动效只负责展示顺序，不得改变锁定稿的最终位置和比例。

## 调用方法

- 合成项：`KeyConclusion`
- 模板文件：`src/templates/KeyConclusion.tsx`
- 示例配置：`presets/key-conclusion.json`
- 对外预览：`previews/key-conclusion-v1.mp4`

使用时复制示例配置，只修改 `label`、`firstPart` 和 `secondPart`。不要修改底图或磨损纹理。

## 验收清单

- 小标签在红色贴纸中居中。
- 主结论在中央撕纸安全区内居中。
- 文字没有超出安全区或压到装饰。
- 文字出现后，字体、磨损和位置保持一致。
- 最后两秒不存在字体切换、闪变或整图覆盖。
- 没有 Logo、横线、发光和具体内容图标。
