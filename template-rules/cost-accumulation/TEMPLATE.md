# 投入累积／资源消耗（已确认）

适用：重复产出、修改版本或尝试次数增加，同时消耗预算或其他资源。
不适用：普通步骤、时间线、无消耗关系的并列观点。不能仅为减少流程图而硬套。

## 可替换内容
- leftTitle/rightTitle：可空，最多8字；说明可空，最多18字。
- resourceCount：2—8；remainingCount：0至起始量减1。单镜头消耗最多7个。
- 消耗一次，增加一张独立素材；数量是示意，不代表真实费用或严格统计。
- art.pile / addition / container / resource：四个独立素材槽。
- 每个槽提供 public 下相对 src、原图 width/height；精灵图可附 crop。
- 默认配图是稿件和钱币。换成时间、精力等主题，必须替换有对应含义的插画，不能只改标题。
- 保持真实比例；自动适配既定区域，不拉伸图片。
- 目前只有16:9布局，不声称适配竖屏。

## 视觉约束
沿用报纸背景、黑白照片剪贴、砖红点缀；无强制页面大标题。
图层在780px以上结束；独立说明从823px开始，字幕安全区960px以后。
不加箭头，不在插画上覆盖文字。不要新增一组无意义计数标签。
红色说明文字固定700字重，保持与既有样片一致，不使用默认常规字重。
入场顺序：插画先出现；0.8秒开始黑色标题淡入上移，1.25秒开始红色说明淡入上移。
文字不得与插画共用入场透明度；文字为空时直接隐藏，不影响其他图层。
素材使用本地图片，不需要每次生图；缺少主题素材时另行制作和确认。
