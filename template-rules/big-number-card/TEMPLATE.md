# 大数字卡模板规则

## 当前状态

已完成静态与动态验收，状态为 `validated`（用户确认：2026-09-30）。

已确认动态样片：`previews/big-number-card-dynamic-v1.mp4`。

## 用途

用于突出一个核心数字，并用少量文字解释数字的口径、变化或实际含义。主角必须是数字，而不是一句普通结论。

## 输入内容

- `headline`：观众真正要回答的问题或结论。
- `context`：左侧对数据口径的简短解释。
- `eyebrow`：数据口径或记录周期。
- `prefix`、`value`、`suffix`：核心数字及单位。
- `label`：数字代表的指标。
- `beforeLabel`、`beforeValue`、`afterLabel`、`afterValue`：左侧小型对照图。
- `footnote`：可选的数据范围或时间说明。

## 视觉边界

- 核心数字直接排版，不能被卡片框住。
- 撕纸只用于左侧的小型对照柱，不铺成大面积底板。
- 标题、解释和脚注直接排版，不强行放进撕纸。
- 数字面积必须明显大于所有说明文字。
- 不适合承载多个并列数字、完整图表或普通金句。
- 分类名称、模板名称、设计说明只属于元数据，不得进入画面。

## 静态验收

- 第一眼先看到核心数字，其次才看到数字含义。
- 前缀、数字和单位不重叠、不越出撕纸载体。
- 标准数字和长数字边界测试均不越出安全区。
