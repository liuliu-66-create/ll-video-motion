# 流程步骤模板规则

## 用途

用于有明确先后顺序的步骤，例如“写稿 → 拍摄 → 录屏 → 剪辑 → 发布”。与多点列举的区别是：流程必须有方向和连接关系。

## 可选构图

- `zigzag`：折线路线，适合强调操作次序。
- `journey`：弯曲旅程，适合强调推进感。
- 两种构图都支持 2～6 步，可以共同保留。

## 输入内容

- `steps[]`：按真实顺序填写步骤名称。
- `variant`：填写 `zigzag` 或 `journey`。
- 步骤序号由模板自动生成。

## 布局规则

- 节点、标签和箭头必须沿同一条路线排列。
- 箭头从当前步骤指向下一步骤，不能只看外形随意摆放。
- 步骤数量变化时调用对应的固定路线，不临时拉伸某条路线。
- 标签文字以其米白撕纸安全区为中心，长文字只缩小字号。
- 具体节点路线见 `layout.json`。

## 动效顺序

第一节点先出现，连接箭头随后展开，再出现下一节点。完成标记最后出现。

## 调用

1. 复制 `presets/process-flow-journey-03.json` 或 `presets/process-flow-zigzag-03.json`。
2. 修改 `steps`，数量限制为 2～6。
3. 使用 `ProcessFlowJourney` 或 `ProcessFlowZigzag` 渲染。

## 验收

- 箭头必须真实连接相邻步骤，方向正确。
- 数字、标签和路线不能互相遮挡。
- 5～6 步仍需保证文字可读。
- 连接线必须保留磨损纸张质感，不能退化为光滑线条。
