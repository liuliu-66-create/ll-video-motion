# 双向趋势（已确认）

适用：两个指标方向相反的定性趋势，如质量提升、价格走低。
不适用：流程、时间线、精确数据图表、没有相反变化关系的并列观点。

## 输入与边界
- risingTitle / fallingTitle：最多8字，可为空。
- risingCaption / fallingCaption：最多12字，可为空，固定700字重。
- resourceCounts：三组严格递减的整数，每组1—6，默认[6,3,1]。
- risingArt / fallingArt：可选替换插画，提供public相对src及真实width/height；适配原定区域，不拉伸。
- 钱币数量为示意，不表示价格比例；照片是作品象征，不是画质改善的证据。
- 默认照片／钱币只适合对应语义，其他主题必须替换匹配插画并重新检查。
- 只支持16:9横屏，目前没有竖屏适配。

## 视觉与动效
保持用户确认的静态布局和报纸背景。无大标题、流程箭头或虚构数值。
默认6秒：0.1秒开始展开两条趋势线；照片从0.55秒起依次出现，钱币从0.75秒起依次出现。
所有插画入场完成后，2.8秒黑字淡入上移，3.3秒红色小字淡入上移。
时长变化时所有阶段同比缩放；文字不得与插画共用入场动画。
文字在右侧独立区域，字幕安全区为y>=960。
最终成片复用源码和参数，不嵌入预览MP4。
