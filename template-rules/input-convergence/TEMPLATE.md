# InputConvergence

已完成静态与动态验收，状态为 `validated`（用户确认：2026-09-30）。

已确认动态样片：`previews/input-convergence-dynamic-v1.mp4`。

## 动画顺序

- 标题进入，输入标签从上至下依次贴入。
- 每条纸带沿自身弧线展开，随后显现短箭头。
- 结果卡最后出现，末尾保留完整画面供观看。
- 1920×1080、30fps、180帧；第165帧用于静态检查。

## 表达用途

- 表达多个来源、条件或材料共同形成一个结果。
- 输入项可以是文字、素材、人员、数据或规则，不绑定某个软件。
- 不用于普通并列列举、顺序流程或逐级递减。

## 视觉边界

- 输入关键词使用真实纤维撕纸标签。
- 每个输入对应一条带纤维纹理和不规则纸边的宽纸带，沿不同弧线汇入结果。
- 纸带可以带小型方向标记，但不得退化为几根孤立细线，也不增加写着“汇合”的解释节点。
- 右侧结果是唯一视觉焦点。
- 画面只保留标题、输入项和最终结果，不显示模板名称或设计说明。

## 参数

- `headline`
- `inputs[].label`
- `inputs[].mark`
- `outputLabel`

## 内容提取边界

- 原文中的输入项和最终结果可以进入画面。
- “汇聚、整合、层级、因果”等仅用于选择构图的内部判断，不自动渲染为文字。
- 除非原文明确强调中间步骤，否则不得为结构补写一个中间关键词。
