# 前后对比模板规则

## 用途

用于同一对象在改变前和改变后的对照。必须同时存在左侧“前”、中间变化箭头和右侧“后”。

## 输入内容

- `beforeTitle`：改变前标题。
- `beforeText`：改变前说明。
- `afterTitle`：改变后标题。
- `afterText`：改变后说明。

## 布局规则

- 左右两组贴纸使用各自完整的复合素材，不能只保留最上层纸张。
- 标题位于黑色或砖红色短贴纸中心，不能把标题底条拉长。
- 说明文字位于下方米白纸中心。
- 中间箭头从左侧指向右侧。
- 具体位置与文字安全区见 `layout.json`。

## 动效顺序

改变前先出现 → 中间箭头出现 → 改变后出现。文字跟随所属贴纸单独贴入。

## 调用

复制并修改 `presets/before-after-compare.json`，然后运行：

```powershell
npm.cmd run render:before-after
```

## 验收

- 左右贴纸的外层碎纸完整。
- 标题底条尺寸不因文字长度发生拉伸。
- 四组文字分别居中，不得靠边。
- 两侧内容不能被画面边缘裁切。
