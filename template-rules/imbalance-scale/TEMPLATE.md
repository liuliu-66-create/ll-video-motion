# ImbalanceScale

已验证模板。静态效果图与动态样片均已通过用户确认。

## 表达用途

- 表达投入与回报、责任与权利、工作量与收益等不对等关系。
- 左右内容不要求是金钱，也不要求使用同一种单位。
- 不用于普通前后对比或单纯的数量升降。

## 视觉边界

- 用倾斜天平作为唯一关系结构，不额外添加箭头。
- 两端使用真实纤维撕纸承载关键词和数值。
- 纸片尺寸与天平高低共同表现视觉重量差异。
- 画面只保留标题、两端信息和一句结论。

## 参数

- `headline`
- `leftLabel`、`leftValue`
- `rightLabel`、`rightValue`
- `conclusion`

## 动效顺序

1. 标题淡入。
2. 左右两端撕纸标签分别进入。
3. 天平由接近平衡逐渐向重量更大的一端倾斜。
4. `≠` 印章落下，最后显示结论与红色划线。

## 验收记录

- 标准输入与长文案、不同单位边界输入均已检查。
- 圆章数字以真实圆心为基准双向居中。
- 标题下方不使用无意义分隔线。
- 静态与动态于 2026-09-30 通过用户确认。
